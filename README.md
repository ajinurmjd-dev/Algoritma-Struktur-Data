# SISTEM RESERVASI RESTORAN (Kelompok 3 - SI UNSIKA 2026)

Proyek ini adalah aplikasi Manajemen Reservasi Restoran berbasis Java CLI (Command Line Interface) yang dikembangkan untuk memenuhi tugas mata kuliah Algoritma dan Struktur Data.

## 🚀 Fitur Utama:
- Operasi CRUD Lengkap (Create, Read, Update, Delete)[cite: 3].
- Algoritma Pencarian: Linear Search (Nama/Kategori) & Binary Search (ID)[cite: 3].
- Algoritma Pengurutan: Bubble Sort (ID/Jumlah Orang) & Selection Sort (Nama)[cite: 3].
- Manajemen Data: Simpan dan Muat data otomatis melalui file 'data_reservasi.txt'[cite: 2, 3].
- Logika Bisnis: Pencegahan Overbooking (Maksimal 30 orang per hari) & Statistik Dinamis[cite: 3].
- Keamanan: Fitur Soft Delete & 2-Step Verification[cite: 3].

## 🛠️ Cara Menjalankan Program:
1. Pastikan Java JDK sudah terinstal di komputer Anda[cite: 3].
2. Pastikan file 'data_reservasi.txt' berada dalam folder yang sama dengan file Java[cite: 2].
3. Buka Terminal atau Command Prompt.
4. Kompilasi file:
   javac SistemReservasi_V1.java
5. Jalankan program:
   java SistemReservasi_V1[cite: 2]
